# Md. Nayeem Hossen — Electrician Portfolio

Personal portfolio for Md. Nayeem Hossen, licensed (ABC) Senior Electrician in Dhaka, Bangladesh.

Static site: HTML, CSS and vanilla JS with GSAP. No build step.

- Preview locally: `python -m http.server 5173`, then open http://localhost:5173
- Contact details and social links: `js/config.js`
